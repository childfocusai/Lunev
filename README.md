# Лендинг «ИП Лунёв Д.М.»

Премиальный лендинг для компании по производству и установке оконных конструкций в Москве и области.

## Стек

- HTML5
- CSS3
- Vanilla JavaScript (без внешних библиотек)

## Структура проекта

- `index.html` — контент и структура лендинга
- `styles.css` — визуальный стиль, адаптив и анимации
- `script.js` — слайдер кейсов, анимация появления секций, валидация формы
- `photo_*.jpg` — фотографии реализованных проектов для блока «Кейсы»

## Запуск

1. Открыть папку проекта.
2. Запустить `index.html` в браузере (двойной клик или Live Server).
