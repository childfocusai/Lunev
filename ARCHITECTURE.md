# ARCHITECTURE

## Общая схема

Лендинг построен как одна страница с якорной навигацией и состоит из семантических секций.

1. `header` — бренд, меню, быстрый клик по телефону.
2. `hero` — ключевое УТП и основные CTA.
3. `solutions` — карточки услуг и направлений.
4. `projects` — слайдер реализованных кейсов.
5. `advantages` — аргументы доверия и типы клиентов.
6. `contacts` — контактные данные и форма заявки.
7. `footer` — финальное позиционирование бренда.

## Данные и контент

- Контент услуг и УТП собран на основе исходной презентации.
- Фото для слайдера подключаются как локальные файлы `photo_*.jpg`.
- Контактные данные статично встроены в разметку.

## Поведение на клиенте (`script.js`)

- Reveal-анимация секций через `IntersectionObserver`.
- Слайдер:
  - Кнопки назад/вперёд.
  - Пагинация (точки).
  - Автопрокрутка.
  - Поддержка клавиатуры и свайпа.
- Форма:
  - Проверка обязательных полей (имя, телефон).
  - Валидация телефона по регулярному выражению.
  - Сообщение об успехе/ошибке без отправки на сервер.

## Визуальная система (`styles.css`)

- Сдержанная премиальная палитра (графит + светлый фон + теплый акцент).
- Адаптивные сетки для desktop/tablet/mobile.
- Микроанимации `200–350ms`, соответствующие конверсионному интерфейсу без перегрузки.
